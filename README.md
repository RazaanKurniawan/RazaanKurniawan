### 🏛️ Executive Summary

Saya adalah **Frontend Developer** dan mahasiswa **Teknologi Informasi** yang berdedikasi membangun aplikasi web modern berskala enterprise. Berpengalaman dalam merancang arsitektur antarmuka yang modular, responsif, dan teroptimasi performanya menggunakan ekosistem modern seperti **Vue 3**, **React.js**, dan **TypeScript**.

Saat ini aktif sebagai **IT Developer (Frontend) di PT Pelita Teknologi Global**, bertanggung jawab memimpin pengembangan modul frontend pada sistem enterprise skala besar seperti platform pembelajaran internal perbankan nasional (BCA LMS) dan sistem penukaran valuta asing (Bali Money Changer).
